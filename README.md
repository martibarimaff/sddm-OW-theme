# Readme

sddm-OW-theme is a sddm theme based on Eucalyptus Drop by Matt Jolly which is an enhanced fork of SDDM Sugar Candy by Marian Arlt. (credited in the `AUTHORS` file)

This theme was primarly made for personal use and with minimal knowledge of the qml programming language. At some point i decided to make it public, but be aware i didn't know what i was doing when working on this (i still don't btw).

It makes use a custom font made by me and an animated version of the Outer Wilds wallpaper background.

For the most part this is a castrated version of Eucalyptus with some tweaks, and as such it is subject to the GPLv3 License (avaiable for reading at `COPYING.md` and `LICENSE`).
